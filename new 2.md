## 2. Абзацы и выделение текста

Это второй абзац.



Это третий абзац. Несколько пустых строк подряд работают как одна.

*Курсив* выделяется одинарными звёздочками.

**Жирный шрифт** выделяется двойными звёздочками.

***Жирный курсив*** выделяется тремя звёздочками.

~~Зачёркнутый текст~~ выделяется двойной волнистой чертой.

## 3. Списки

Маркированный список:

* пункт со звёздочкой
* ещё один пункт
+ пункт с плюсом
+ ещё один пункт
- пункт с минусом
- ещё один пункт

Нумерованный список (цифры в исходнике одинаковые):

1. Первый пункт
1. Второй пункт
1. Третий пункт

Нумерованный список (цифры вразнобой):

5. Первый пункт
2. Второй пункт
9. Третий пункт

## 4. Блок кода

Фрагмент программы на C++:

    #include <iostream>
    using namespace std;

    int main() {
        cout << "Hello, Markdown!" << endl;
        return 0;
    }

Код также можно оформить тройными обратными кавычками:

```cpp
int a = 5;
int b = 7;
cout << a + b;
```

Короткий код внутри строки: `cout << x;`

## 8. Формулы TeX

Формула внутри строки: $(x+a)^n$.

Формула отдельной строкой (бином Ньютона):

$$(x+a)^n = \sum_{k=0}^{n} \binom{n}{k} x^k a^{n-k}$$

Сумма геометрической прогрессии:

$$S_n = \sum_{k=0}^{n-1} q^k = \frac{1-q^n}{1-q}$$

Интеграл:

$$\int_0^1 x^2 \, dx = \frac{1}{3}$$
